## Project

"Luxgirl" — a jewelry store built with Next.js 16 (App Router), React 19, Prisma 7 (PostgreSQL), and Tailwind CSS v4. The project is in early scaffolding: most route pages are placeholders. UI copy is in Spanish.

## Commands

```bash
npm run dev      # Start dev server (http://localhost:3000)
npm run build    # Production build
npm start        # Serve production build
npm run lint     # ESLint (eslint-config-next + TypeScript)
```

Prisma (the client is NOT auto-generated by install — run after schema changes):

```bash
npx prisma generate              # Regenerate client into app/generated/prisma
npx prisma migrate dev --name X  # Create + apply a migration
npx prisma studio                # Inspect the database
```

There is no test framework configured yet.

## Architecture

- **App Router** under `app/`. Routes use nested layouts: `app/layout.tsx` is the root (sets the Righteous Google font and `bg-gray-200` body); `app/order/layout.tsx` wraps order routes in a three-pane flex shell — `OrderSidebar` (left), `main` content, and `OrderSummary` (right `<aside>`).
- **Components** live in `components/`, grouped by feature (e.g. `components/order/`). Imported via the `@/*` path alias, which maps to the repo root (`@/components/...`).
- **Prisma** is configured via `prisma.config.ts` (not the legacy `package.json` block). The schema is at `prisma/schema.prisma`; the `DATABASE_URL` is read from `.env`. The generated client outputs to `app/generated/prisma` (gitignored) using the new `prisma-client` generator — import the client from there, not `@prisma/client`. The schema currently defines no models.
- **React Compiler** is enabled (`reactCompiler: true` in `next.config.ts`), so manual `useMemo`/`useCallback` memoization is generally unnecessary.
- **Tailwind v4** is wired through PostCSS (`@tailwindcss/postcss`); global styles in `app/globals.css`. There is no `tailwind.config` file — configure via CSS.

## Notes

- `.env` holds `DATABASE_URL` and is gitignored; never commit it.
- TypeScript is strict mode with `noEmit` (Next handles the build).
